问题

每次验证码，都要人肉搬运一遍

在电脑上注册、登录、绑卡，验证码永远发到手机上。你只有三条路，条条都要放下手上正在干的事。

共同的起点：在电脑端的网站点击发送短信 —— 接下来怎么拿到验证码，差距就在这里
传统方式起点与终点之间，全靠人肉搬运
  • 微信中转拿起手机解锁，查看、复制短信，打开微信，粘贴、发送到电脑微信，电脑端切换到微信，复制验证码，切回到网站，粘贴验证码9 步
  • 背诵手输拿起手机解锁，查看、背诵验证码，手工逐个数字输入验证码3 步
  • 输入法同步拿起手机解锁，查看、复制验证码，（通过输入法经服务器同步到电脑的剪贴板），粘贴验证码3 步
SmsSink 方式起点与终点之间，一步到位1步到位

无需打开手机查看，无需打开微信等即时通讯工具接收验证码，也无需经过第三方服务器同步验证码——全程只在电脑端：

  • 「发送 → 复制 → 粘贴」全在电脑端完成，一气呵成。
  • 如果开启「自动复制」功能，还能实现「发送 → 粘贴」一步到位。

原理

三步，全部发生在你自己的设备之间

手机装一个开源的 SmsForwarder 负责转发，电脑跑 SmsSink 这个单文件 exe 负责接。两端在同一个 WiFi 里直接对话，没有中间人。

1手机收到短信SmsForwarder 识别出验证码，按你配的规则提取
2经 WiFi 直发电脑POST 到你电脑的局域网地址，不经云端
3右下角弹卡点「复制」即可粘贴，也可开启自动复制
隐私

你的验证码，只有你和你自己的电脑知道

不经过第三方服务器短信内容只在手机与电脑之间传输，不落到任何云服务、不注册账号、不联网上报。
可选加签校验开启后只有持密钥的手机能发消息，同一 WiFi 下的其他设备发不进来。
数据只存在本机记录写在本机 data.db，卸载时删掉两个文件夹即可彻底清空，不留残余。
适合谁

它解决一个很具体的问题，也很诚实地承认边界

适合你，如果——

  • 每天要在电脑上登录、注册、绑卡
  • 验证码短信多到厌烦拿起手机
  • 在意隐私，不想让验证码经过任何云端
  • 用 Windows，手机是安卓

暂时不适合，如果——

  • 手机是 iPhone（SmsForwarder 只支持安卓）
  • 手机和电脑从不在同一个网络
  • 需要远程跨网收验证码
常见问题

上手前，你可能想知道

需要 root 或者越狱吗？不需要。转发端用的是安卓系统的短信读取权限，装个 App 授权即可。
要一直开着电脑吗？电脑端没有主窗口，开机自启、缩在托盘里，几乎不占资源。电脑关机时自然收不到。
换了 WiFi 或路由器重启后失效？电脑的局域网 IP 可能变。回管理台复制新地址，更新到手机端即可，一分钟的事。
会额外收费吗？不需要。全程走你自己的局域网，不消耗服务器资源，也没有账号体系。
